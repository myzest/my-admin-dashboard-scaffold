# UI 布局与公共表格

## 页面布局

已登录页面通过 `AppLayout` 共用视口高度容器。顶部栏与左侧导航保留在原位；普通页面由右侧 `main` 滚动，菜单过长时在左栏内部滚动。

页面和面板标题统一只展示标题及必要操作，不附带简短说明；登录、注册面板沿用这一规则。

| 视口宽度   | 导航默认行为                   |
| ---------- | ------------------------------ |
| ≥ 1024px   | 展开，可手动收起               |
| 768–1023px | 收起，可手动展开               |
| < 768px    | 隐藏侧栏，通过顶部按钮打开抽屉 |

`LayoutPreferencesProvider` 保存本次应用会话中的折叠选择，客户端切换路由后保持；刷新页面后恢复按屏宽确定的默认状态。移动抽屉支持遮罩、关闭按钮与 Escape 关闭，选中菜单后关闭，关闭后焦点回到入口按钮。

页面高度使用 `100dvh`，通过 `visualViewport` 更新可见高度和偏移量，以适应窗口变化和移动浏览器可见区域变化。矮屏内容超过最小可用高度时，允许右侧主内容滚动。

## AdaptiveTable

用户、分类、管理员余额日志、用户余额日志和操作日志均使用 `src/components/AdaptiveTable.jsx`。它只负责展示布局，不请求接口，也不处理业务权限。

```jsx
<section className={`${styles.panel} ${styles.listPanel}`}>
  <ListToolbar actions={<Button onClick={refresh}>刷新</Button>}>{/* 筛选表单 */}</ListToolbar>
  <RequestError error={error} onRetry={refresh} />
  <AdaptiveTable
    rowKey="id"
    columns={columns}
    data={data.items}
    loading={isLoading}
    scroll={{ x: 1000 }}
    pagination={{ current: page, pageSize, total: data.pagination.total }}
    onChange={({ current, pageSize }) => changePage(current, pageSize)}
  />
</section>
```

- 父容器负责提供剩余空间。表格根据容器、表头和分页的实际尺寸计算表体高度，默认保留至少 `180px` 表体空间，可通过 `minBodyHeight` 调整。
- 少量数据和空态保留可用高度；长列表仅表体纵向滚动。表头与分页位于表体之外，横向滚动条位于可见表体底部，无需滚到全部记录末尾。原生滚动条是否自动隐藏遵循操作系统设置。
- `ResizeObserver` 跟随筛选展开、错误提示、分页换行和容器尺寸变化重新测量，避免每个页面分别维护固定高度偏移量。
- `scroll.x` 仍由业务表格指定；组件管理 `scroll.y`、表头/表体 wrapper 和分页容器。表格标题、工具栏、错误提示放在表格外，与现有页面一致。
- `columns` 使用当前项目的平铺列结构。桌面沿用业务列的 `fixed` 设置，移动端取消固定列，保留完整横向滚动。表格容器宽度小于 `480px` 时使用简洁分页。
- 翻页、改变每页条数、排序和表格筛选回到表体顶部；同页刷新保留滚动位置。头部与表体的横向同步继续使用 Arco 原生实现。

Arco 会合并自定义组件定义，因此表头/表体的 `components` 配置定义为模块常量，避免表体被重新挂载导致滚动位置丢失；公共组件统一管理这份配置。分页可能延后挂载，使用节点 ref 在挂载后重新订阅尺寸变化。

## 配套组件

- `ListToolbar`：桌面直接显示筛选；移动端点击“筛选”展开条件区，再次点击“收起筛选”隐藏条件区。输入先作为草稿，点击“查询”后才请求数据、回到第一页并更新条件数量；收起和再次展开保留草稿与已应用条件。查询后保留展开状态。清空输入再查询即可取消条件，操作日志还可使用“重置”清空全部条件。
- `ExpandableText`：点击或键盘激活查看完整内容，弹层支持长文本换行与内部滚动。Escape 或表体滚动时关闭弹层；点击按钮时显式聚焦，保证 Safari 也能接收 Escape。
- `ResponsiveModal`：弹窗宽度受视口限制，标题和按钮区保持可见，表单内容内部滚动。表单按钮放在 `footer`，通过 `form` 属性连接表单，保留提交、校验和加载状态。通过 Arco 的 `getChildrenPopupContainer` 将 Select 等子弹层挂到 `document.body`，避免被内容滚动区裁切。

用户表的编辑、调整余额保留直接入口，其余操作进入“更多”。菜单支持 Escape 关闭，表体滚动时关闭。日志菜单项用 Next.js `Link` 作为 `Menu.Item` 的 wrapper，并显式覆盖 Arco 默认的 `onKeyDown`，让 Enter 触发原生链接点击，保留客户端导航和新标签打开能力。金额保留原始四位小数字符串、右对齐，并预留完整显示宽度。

## 实现复审

本轮沿公共布局、全部列表调用、弹窗和业务回归链路复查，修复了以下可复现问题：

- 日志链接嵌在菜单项中时，菜单获得焦点后按 Enter 不会激活链接。改为链接直接承载菜单项，并避开 Arco 提前转移焦点的默认按键处理。
- 在 `390×320` 视口打开调整余额弹窗，下拉列表的“扣减”选项被滚动容器裁切。改用 Modal 公共子弹层挂载配置。
- 表体滚动后，全文弹层与“更多”菜单仍悬在原位置。启用 Arco 的容器滚动关闭配置。
- WebKit 点击按钮不自动聚焦，导致 Escape 不能关闭弹层。触发按钮显式聚焦，并保留防止页面跳动的 `preventScroll`。
- 移动筛选按钮覆盖了 Arco 原生布局，使用 `inline-flex` 后图标和文字偏向按钮顶部。恢复 `inline-block`，沿用组件库的内容对齐方式，保留 `44px` 触控高度。
- 余额日志页用 URL 条件作为整个页面的 React key，提交查询时会重挂载筛选区、丢失展开状态。移除页面级 key，仅在 URL 条件变化时同步输入草稿和页码，保留工具栏状态。

删除了公共表格中无人使用的自定义组件合并、分组列递归和重复测量依赖，以及失去调用方的 `.menuLink` 样式。精简部分净减 19 行，不计错误修复、回归测试和文档变更。

## 验证与边界

`tests/e2e/layout.spec.js` 覆盖桌面/移动/平板切换、少量与空数据、表头横向同步、刷新/翻页、错误提示后的高度重算、筛选收起、菜单 Escape 与焦点恢复、矮屏弹窗及下拉选项、日志菜单键盘激活、滚动时关闭浮层、主内容和左栏独立滚动、登录/注册的小屏可达性。接口文档测试补充锚点定位与移动导航回归。

移动筛选另逐页覆盖用户、分类、余额日志和操作日志：在 `320/390/767px` 检查图标和文字相对按钮的中心位置，在 `768px` 检查切回直接显示筛选；使用触屏点击验证展开、填写、查询请求参数与结果变化、条件计数、收起后保留输入和清除条件。操作日志还覆盖动作和对象类型组合筛选。验收需查看各页展开与收起截图，不能只依赖控件可见性断言。

运行 `npm run test:e2e`，测试入口使用 `.env.test.local` 指定的独立测试数据库和临时生产构建。布局测试使用受控列表数据，不向业务数据库插入大量测试记录。

2026-10-25 复审后验证结果：生产构建、ESLint、Prettier、34 项单元测试、20 项 Chromium 浏览器测试全部通过；另通过临时隔离测试入口调用 Playwright `test layout.spec.js openapi.spec.js --browser webkit`，使用 WebKit 27.2 验证 11 项布局测试与 1 项接口文档测试，全部通过。补充筛选展开/收起后的分页底边位置断言后，Chromium 和 WebKit 各 12 项针对性回归均通过。覆盖宽度 320/390/767/768/820/844/1024/1366px、320/390px 矮屏弹窗和 320px 高度的独立滚动。

本轮没有新增业务功能或未确认的交互方案。真实 iOS 软键盘、浏览器工具栏和刘海安全区仍需设备验收，桌面 WebKit 的视口测试不能替代真机验证。
