## 已确认范围

## 当前实现边界

- 会话有效期 12 小时，数据库保存会话记录；退出后撤销对应记录。Cookie 使用 `HttpOnly`、`SameSite=Lax` 和显式的 `secure: false`。
- 双角色升级将 Cookie 名由 `admin_session` 改为 `starter_session`，旧浏览器需重新登录；账号密码不变。修改密码撤销全部会话。
- 登录限流为每个 socket IP、每个进程 15 分钟内最多 10 次尝试；不信任客户端传入的 `X-Forwarded-For`。反向代理后访问可能共享代理 IP 的配额，多实例共享限流需后续另行设计。
- 公开注册独立使用相同的限流额度；关闭注册与注册事务通过设置行锁确定提交顺序。管理员创建用户不受注册开关影响。
- 管理员初始化不提供默认密码，重复运行不会重置已有管理员。修改环境变量中的初始密码不会修改数据库中的密码。
- MySQL 迁移包含自动提交的 DDL。发布前备份数据库，并由单个部署进程执行迁移。
- 当前 React 19 + Arco 组合通过公开的 `Message.useMessage()` 显示提示，弹窗使用受控组件；不依赖 Arco 的私有兼容补丁或全局样式覆盖。
